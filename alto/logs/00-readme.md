# Read me: Website (altioraai.com) logs and decisions

This folder is the written history of the Altiora AI website: what was changed, what was decided and why, and what is still open. It covers the work done with Claude from 15 November 2026 onwards.

## What is in this folder

| Document | What it holds | When to use it |
|---|---|---|
| 01 Change log | Every change made to the website, in date order | "What changed, and when?" |
| 02 Decisions register | Every decision, who made it, and the reason | "Why is it like this?" |
| 03 Open items and next steps | Everything waiting on someone, with the next action | "What is left to do?" |

The other folders next to this one:

- **02 Technical reference:** where everything lives (Webflow pages, code, translation files, settings), so anyone can maintain the site.
- **03 Briefs and Handovers:** instructions written for other people or other Claude sessions, such as the Recall beta brief and the enquiry pipeline setup.

## How to keep it up to date

- Add new changes to the bottom of the change log, with the date.
- Any decision that changes how the site works goes in the decisions register, with the reason.
- When an open item is done, move it to the change log and remove it from open items.
- Times are Dubai time (GST, UTC+4).

## Where the source files live
