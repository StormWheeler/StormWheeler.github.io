# Home page redesign (approved 23 Nov 2026)

`home-redesign-preview.html` is the approved clickable preview of the new altioraai.com home page. It is the reference for the Webflow build.

- Scroll film opening with a time-of-day greeting and a "What brings you here?" choice. The choice reorders the page and is remembered only in the visitor's own browser (localStorage key `altiora-path`). Nothing is sent anywhere.
- Tessera teaser: a scroll film of a room waking, a room panel, and the token assembling. No technical details, partners or prices.
- Recall stage: a 3D phone playing real app footage, then a one-minute mini session that runs entirely in the browser (no data stored or sent), and the Recall icon assembling.
- Media (film frames, app clips) are not kept in this public repository. They live in the Webflow assets once built.
