# Altiora AI – English to Arabic glossary and style rules

Audience: hotel, holiday-home, venue and event managers in the UAE. Write clear, formal Modern Standard Arabic (فصحى) as used by UAE businesses. Calm, exact, premium; no hype, no exclamation marks, no emoji. Short sentences. Use Arabic punctuation (، ؛ ؟) and keep Western digits (0-9) as in the English, e.g. 23:47, 12 to 14 March → 12 إلى 14 مارس.

Fixed terms (use exactly):
- Altiora AI → ألتيورا للذكاء الاصطناعي (short form where natural: ألتيورا)
- Altiora → ألتيورا ; Altiora Labs → ألتيورا لابز ; Tessera → تيسيرا ; Alto → ألتو
- Storm Wheeler → ستورم ويلر ; United Arab Emirates → دولة الإمارات العربية المتحدة ; UAE → الإمارات
- AI → الذكاء الاصطناعي ; system → نظام ; operation(s) → العمل / التشغيل ; handover → التسليم
- guest → الضيف ; holiday homes → بيوت العطلات ; venues → المنشآت ; event teams → فرق الفعاليات ; hospitality → الضيافة
- WhatsApp → واتساب ; CRM → نظام إدارة علاقات العملاء (CRM) ; RFP → طلب تقديم العروض
- automated assistant → مساعد آلي ; lock-in → ارتباط ملزم ; "A person approves what matters" → شخص يوافق على كل ما يهم
- Privacy notice → إشعار الخصوصية ; Terms of use → شروط الاستخدام ; AI use and disclaimer → استخدام الذكاء الاصطناعي وإخلاء المسؤولية ; Cookie notice → إشعار ملفات تعريف الارتباط
- PDPL / Personal Data Protection Law → قانون حماية البيانات الشخصية (المرسوم بقانون اتحادي رقم 45 لسنة 2021)
- licensed / trading → مرخّص / يمارس نشاطًا تجاريًا
- Keep unchanged: email addresses, URLs, phone numbers, brand names of third-party products (Webflow, Google Workspace, Plausible), "AED".
- Tagline: "Think higher. Build smarter." → فكّر أعلى. ابنِ بذكاء أكبر.
- "Technology choices come last. System integrity comes first." → اختيار التقنية يأتي أخيرًا، وسلامة النظام تأتي أولًا.

Legal text: translate faithfully and completely, never soften or add obligations. Keep section numbers. Keep article references (e.g. "Articles 4 and 6" → المادتان 4 و6).
